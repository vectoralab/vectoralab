# VectoraLab

**Edge-assisted condition monitoring for industrial machinery.**

VectoraLab is an industrial technology project focused on monitoring the condition of rotating machinery using vibration sensing, embedded systems, digital signal processing, and machine learning.

## What we're building

VectoraLab follows a two-level architecture:

**Machine → Vibration Sensor → Edge Processing → Signal Analysis → Health Assessment → Software**

Current development includes:

* **IIS3DWB** vibration sensing
* **STM32H750** edge-processing platform
* **5 kHz** vibration sampling
* Time-domain and frequency-domain signal analysis
* Software-based machine **Health Score**
* Embedded **INT8 TinyML** development

## Current status

The software analysis layer is implemented, including vibration analysis and Health Score functionality.

The hardware prototype and PCB are currently under construction, while embedded signal processing and INT8 TinyML inference are under development.

The public repository contains selected technical documentation, signal-processing examples, synthetic vibration datasets, and a standalone Python vibration analyzer.
